A combat and skill system coded in Luau for a Demon Slayer Roblox game

Language: Luau
Engine: Roblox Studio

Context:

I developed this system while working as a programmer for a Roblox game studio, where I was the Head Developer and Lead Programmer and responsible for the core mechanics of the game like: Combat, skills, creating the framework and the rest of the game.

My main focus with this system is making everything completely reusable in other systems or in other projects, while also keeping it very readable. Basically Object Oriented Programming.

Features:

Modular combat
Reusable functions and components
Organized and maintainable
Guard clausing (cause it's peak)
Designed with extensibility in mind
